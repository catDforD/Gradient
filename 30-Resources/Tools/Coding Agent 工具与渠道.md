# Coding Agent 工具与渠道

相关：[[AI 与 Coding]] · [[Vibe Coding]]

**1. Codex + VSCode（代码编辑器，我一般用这个）**  
适合在熟悉的编辑器环境里直接接入 agent 能力。  
一边写代码、一边让 Codex 做理解、补全、重构、调试，整体体验更偏 IDE 增强型助手。  
优点是上手自然、编辑体验完整，比较适合作为日常主力工具。

**2. Claude Code（CLI 使用体验更好）**  
终端交互体验很强，读代码库、跨文件修改、执行命令、排查问题都比较顺。  
更像一个能直接在命令行里协助干活的 coding agent。  
优点是效率高、反馈直接，做工程类任务时手感很好。

**3. OpenCode（开源项目工具）**  
开源、灵活、可定制，适合自己搭工作流。  
可以结合不同模型和 API 使用，也方便研究 agent 工具本身的实现方式。  
优点是开放性强、可控性高，扩展空间比较大。

## Coding Plan

**1. Kimi Coding Plan（贵，效果第二梯队顶级）**  
整体代码能力强，理解、生成和交互表现都不错。  
优点是效果稳定、体验在线；Kimi 的前端能力还不错，缺点是价格偏高。  

**2. 咸鱼 GPT Business Team 拼车（推荐，第一梯队顶级）**  
综合性价比很高，能力和成本之间平衡得最好。  
如果车稳定、渠道靠谱，通常是最值得优先考虑的方案。  

**3. GLM Coding Plan**  
更偏务实型方案，能满足基础到中等强度的 coding 需求。  
优点是门槛相对低，GLM5 能力还行，但是智谱的方案很不靠谱，不建议。
