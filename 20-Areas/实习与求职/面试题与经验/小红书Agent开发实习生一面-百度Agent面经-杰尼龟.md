## 百度 Agent 面试题目

### 项目与业务理解

1. 自我介绍；追问上一段实习的细节，例如为什么没转正、后续秋招安排。
2. 介绍项目：面向什么业务场景、给谁使用、是内部工具还是外部产品、解决什么痛点。

### Agent 工作流与 LangGraph

3. 项目中的子图为什么要放多个小节点？
4. 为什么要结合 LangGraph 和子 Agent 完成工作，而不是使用一个大 Agent 或脚本？
5. AI 节点的输入和输出是如何对接的？
6. 上下文 / 数据是如何在节点之间传递的？
7. 如果用 Skill 生成下游的文本或文件，但出现幻觉、路径写错等问题，如何处理？

9. 人工删除图片的行为如何实现？

## 面试结果与作者复盘

- 作者表示：百度面试约半小时结束，没有手撕，整体感觉没有问深入；小红书面试约 1 小时，手撕给出 Java 后端八股，但后续没有继续深入。

## 高频主题归纳

- Agent 工作流：Pipeline、子图、子 Agent、节点编排、路由和执行闭环。
- LangGraph：State 传递、节点输入输出、子图独立运行和重复执行。
- Skills：知识进化、动态注入、文件生成、幻觉与路径错误处理。
- 后端基础：MySQL 索引、B+ 树 / B 树、锁机制。
- 工程实践：AI Coding、Claude 使用习惯、自动化评估和长链路可维护性。
- 算法基础：最长递增子序列。
