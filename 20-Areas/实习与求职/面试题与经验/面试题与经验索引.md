# 面试题与经验

这里集中记录实习、校招和社招中的面试流程、题目、回答和复盘。面试题先记录原始口径，再补充自己的回答、知识缺口和后续准备。

## 使用方式

1. **新面经进来**：先按原有格式写成面经笔记（保留公司、轮次、结果等上下文），再抽取其中的知识类题目归入下方题库，回链出处。
2. **复习时**：按题库专题刷题，每道题带考点要点和出处链接，需要上下文时回到原面经。
3. 🔥 标记表示题目在多份面经中重复出现，优先复习。

## 备考优先级（基于出现频率）

1. Agent 架构 + 上下文记忆：每场必问，先成体系过一遍
2. MCP / Skills / Function Calling 概念边界：2026 年新热点，多份面经反复出现
3. 高并发优惠券（AI Coding）+ LIS：已知重复出现的实操题，精准准备
4. 后端八股（HashMap / MySQL / 线程池）：Agent 岗没有豁免
5. RAG：投算法岗时优先级提到最前

## 待补充的复盘维度

- 面试时间、面试时长和面试官背景
- 每道题自己的回答、追问和失分点
- 题目对应的知识笔记或代码练习
- 复盘后的改进动作与再次面试表现
