## 面经 07｜AI Agent 开发｜2026-04-12

### 多阶段 RAG 与文档处理

2. 多阶段 RAG 中为什么不能只做一次召回？二段甚至三段检索分别解决什么问题？

4. 结合 OCR 和文档解析，为什么要引入结构化中间层，而不是直接把全文送入向量库？

### Agent 状态与工具工程

5. Agent 系统中 State 管理和 Checkpoint 机制为什么是核心，而不只是工程细节？
6. LangGraph 的 Checkpoint 和 Memory 到底有什么区别？
7. 对话执行中出现状态竞争问题时，通常如何解决？
8. 将 Choice 接口封装成 MCP 工具时，为什么参数设计和输出约束都很关键？

10. Agent 单个节点的 Token 预算一般如何控制？为什么这件事比想象中更重要？
11. 如果任务失败（例如数据获取为空），整个工作流如何设计恢复逻辑？

### 主题

- BM25、向量召回、混合检索、多阶段检索和 RAG 评估。

- LangGraph State / Checkpoint / Memory、状态竞争、Token 预算和失败恢复。
- MCP 工具约束、FastAPI 与 SSE 流式执行。
