## 高频题（已出现多次）

- **最长递增子序列（LIS）**（🔥 出现两次：小红书两场）
	- O(n²) 动态规划 + O(n log n) patience sorting 两种写法都要会。
	- 出处：[[20-Areas/实习与求职/面试题与经验/小红书-Agent服务端开发实习-一面面经|小红书·服务端]]、[[20-Areas/实习与求职/面试题与经验/小红书Agent开发实习生一面-百度Agent面经-杰尼龟|小红书/百度·杰尼龟]]
  > [!success]- ✅ AI 解答 · Q16 · 2026-09-16
  > **🎯 标准答案（面试版）**两种写法都要会：①O(n²) DP：dp[i]=以 i 结尾的 LIS 长度，dp[i]=max(dp[j]+1 | j<i 且 nums[j]<nums[i])，答案为 max(dp)，记录前驱可恢复具体序列；②O(n log n) 贪心+二分（patience sorting）：tails[k] 维护「长度 k+1 递增子序列的最小尾元素」，每元素 bisect_left 定位替换或追加，tails 长度即答案。
  > **📌 要点**
  > - 严格递增用 bisect_left（相等元素不扩展长度），非递减用 bisect_right
  > - tails 不是具体 LIS（只保证长度正确），恢复序列要用 DP 前驱法
  > - 边界：空数组返回 0；全相同元素严格 LIS=1
  > - 变体：最长递增子序列个数、俄罗斯套娃信封（排序一维后做 LIS）
  > **🔬 原理深入**
  > patience sorting 直觉：牌面分堆、每堆递增、堆顶最小——新牌放最左的 ≥ 它的堆顶上，堆数即 LIS 长度；替换策略保证 tails 严格递增（归纳可证），二分使单步 O(log n)。DP 正确性来自最优子结构：以 i 结尾的 LIS 必由某个 j<i 的 LIS 延伸而来。追问：为什么二分而不是线性找？——总复杂度从 O(n²) 降到 O(n log n) 的关键，n=1e5 规模下 O(n²) 会超时。
  > **🔗 延伸**
  > 面试策略：先讲 O(n²) 暴力再主动优化到 O(n log n)，展示优化路径比直接背最优解更得分；与编辑距离同属「序列 DP → 贪心+数据结构优化」范式。

  > **🎯 标准答案（面试版）**两版代码一次给全：
  > ```python
  > def lis_dp(a):                        # O(n^2)
  >     if not a: return 0
  >     dp = [1] * len(a)
  >     for i in range(len(a)):
  >         for j in range(i):
  >             if a[j] < a[i]: dp[i] = max(dp[i], dp[j] + 1)
  >     return max(dp)
  >
  > def lis(a):                           # O(n log n)
  >     tails = []
  >     for x in a:
  >         i = bisect_left(tails, x)
  >         if i == len(tails): tails.append(x)
  >         else: tails[i] = x
  >     return len(tails)
  > ```
  > **📌 要点**
  > - 严格递增用 bisect_left（相等不扩展）；恢复序列要额外记前驱索引或桶内回溯
  > - 现场话术：先 30 秒讲清两版复杂度差异与升级理由，再动笔（先暴力、后优化是加分项）
  > - 边界：空数组 0；全相同元素严格 LIS=1；负数无需特殊处理
  > **🔬 原理深入**
  > tails 单调性证明（交换论证）：若某长度的尾元素不是最小，替换成更小尾部不会破坏后续可行性，故 tails 严格递增可二分。复杂度来源：DP 每点扫全部前驱 O(n²)；patience 把「找第一个 ≥ x 的位置」交给有序表二分 O(log n)。延伸变体：套娃信封（W 升序、H 降序后做 LIS，降序防同宽重复计数）、LIS 个数（树状数组按值域统计）。

## 数据结构基础

- **手撕：二叉树遍历** —— 前中后序递归+迭代、层序；注意面试官可能追问 Morris。出处：[[20-Areas/实习与求职/面试题与经验/AI-Agent与大模型岗位面经汇总-01至05-07-08|汇总A·面经02]]
  > [!success]- ✅ AI 解答 · Q140 · 2026-09-28
  > **🎯 标准答案（面试版）**递归版三行核心（根-左右/左-根-右/左右-根）。迭代版用显式栈：前序=访问根后先压右再压左；中序=一路压左链，弹栈访问后转向右子树；后序=前序变形（压左先压右得「根右左」）再 reverse，或用「上次访问节点」双条件判断。层序用 BFS 队列，按层处理时先快照当前队列长度。Morris 遍历 O(1) 空间：找中序前驱置线索、回溯时恢复。
  > **📌 要点**
  > - 中序迭代模板：while 栈非空或节点非空——压左链→弹出访问→转右
  > - 后序易错点：仅靠右子是否访问过判断，需记录 prev
  > - 层序分层：每轮 len(queue) 快照；变体之字形用双端队列
  > - 复杂度：遍历 O(n)；递归/栈空间 O(h)，Morris O(1)
  > **🔬 原理深入**
  > 原理：递归本质是隐式调用栈，迭代=手动管理栈还原控制流；Morris 利用「空右指针」临时指回中序后继，访问完恢复树结构，代价是短暂改树。高频追问：莫里斯中序如何找前驱（左子树最右节点）、之字形层序（deque 头尾交替）、N 叉树层序。
  > **🔗 延伸**
  > 与本库 LIS（Q16）、MHA（Q14）同属必练手撕；语言按岗位准备 Python 与 Java 双版本。

  > [!success]- ✅ AI 解答 · Q140 · 2026-10-15（复习轮）
  > **🎯 标准答案（面试版）**现场流程五步：先声明节点结构 → 写递归三行（前/中/后序差异只在访问位置）→ 主动询问「要不要写迭代版」→ 再提 Morris 作为 O(1) 空间选项。Morris 中序口诀：找前驱（左子树最右节点）→ 让其右指针临时指回自己形成线索 → 访问完恢复树结构。
  > **📌 要点**
  > - 中序迭代模板：while(栈非空 || 节点非空){ 压左链 → 弹出访问 → 转右 }
  > - 后序迭代易错点：不能只看右子树是否存在，需要 prev 指针记录「右子树是否刚访问完」

  > **🔬 原理深入**
  > 递归与迭代的本质关系：递归是隐式调用栈，迭代是手动还原同样的控制流，h 为树高时两者空间都是 O(h)；Morris 用「空右指针」这一免费资源做临时线索，把空间降到 O(1)，代价是遍历过程中短暂修改树结构（并发场景需谨慎）。

- **n 人排队随机淘汰奇数位置，问哪个位置获胜概率最大** —— 数学/递推题：列小规模递推找规律。出处：[[20-Areas/实习与求职/面试题与经验/AI-Agent开发岗位面经汇总-2026年4月-01至07|汇总B·面经01]]
  > [!success]- ✅ AI 解答 · Q148 · 2026-09-29
  > **🎯 标准答案（面试版）**这是约瑟夫环变体的确定性递推题。设 f(n) 为 n 人时最终幸存者的原始位置（1-indexed）：每轮淘汰当前奇数位后剩 ⌊n/2⌋ 人，原偶数位 i 的人在新序列中编号为 i/2。因此新序列第 j 人对应原序列第 2j 位，得递推 f(1)=1，f(n)=2·f(⌊n/2⌋)，O(log n) 直接迭代；展开为封闭式 f(n)=2^⌊log₂n⌋（即不超过 n 的最大 2 的幂）。由于过程完全确定，答案是一个固定位置而非概率分布——n 恰为 2 的幂时幸存者是最后一位，否则幸存者位于「不超过 n 的最大 2 的幂」处。【2026-10-16 修正：原稿封闭式 2·(n−2^⌊log₂n⌋) 在 n 为 2 的幂时得 0，已更正为 2^⌊log₂n⌋】
  > **📌 要点**
  > - 递推：f(1)=1，f(n)=2·f(⌊n/2⌋)，O(log n)
  > - 封闭式：f(n)=2^⌊log₂n⌋（≤n 的最大 2 的幂）
  > - 题眼：淘汰后「重新编号」，新编号 j ↔ 原编号 2j 的确定映射
  > - 面试策略：先手算 n=1..8 找规律，再归纳出递推式
  > **🔬 原理深入**
  > 为什么「重新编号」是本题核心？每轮后队伍长度减半，幸存者相对次序不变，新旧编号存在确定映射——这正是递推的来源，结构上比经典 Josephus（f(n)=(f(n−1)+k) mod n）更简单。易错点：1-indexed/0-indexed 混用、n 为 2 的幂时无需偏移。变体追问：改淘汰偶数位（f(n)=2·f(⌊n/2⌋)−1，n>1）；报数到 k 出列的标准 Josephus 用 O(n) 递推或 O(k log n) 树状结构解。若题目真问概率（每轮随机重排），才需要概率分析，确定性版本直接给闭式更有说服力。

  > 与 LeetCode 1823（约瑟夫环）同源；递推找规律题的通用套路：小规模暴力 → 列表观察 → 归纳通项/递推 → 验证边界。

  > **🎯 标准答案（面试版）**这是「淘汰后重新编号」型递推题，先手算建表：n=1→1、2→2、3→2、4→4、5→4、6→4、7→4、8→8。规律是每轮淘汰奇数位后剩 ⌊n/2⌋ 人，原偶数位 2j 变成新编号 j，故 f(n)=2·f(⌊n/2⌋)、f(1)=1，O(log n)。封闭式：f(n)=2^⌊log₂n⌋，即 ≤n 的最大 2 的幂（二进制只保留最高位 1、其余清零）。
  > **📌 要点**
  > - 手算表背下来就是面试底气：1→1 2→2 3→2 4→4 5→4 6→4 7→4 8→8
  > - 递推 f(n)=2·f(⌊n/2⌋)；封闭式 = ≤n 的最大 2 的幂
  > - 二进制直觉：n=5=101b → 保留最高位 → 010b=2 ✓
  > - 三行代码：`def f(n): return 1 if n==1 else 2*f(n//2)`
  > **🔬 原理深入**
  > 为什么这类题「找规律」比套公式快？面试只有 5 分钟，手算 n≤8 约 30 秒，归纳递推后用「重新编号映射」解释其成立——比背约瑟夫环公式更有说服力，也避开约瑟夫环 f(n)=(f(n−1)+k) mod n 的干扰（本题从头部淘汰、结构更简单）。易错点：1-indexed 与 0-indexed 混用；另一个高频坑是把封闭式写成 2·(n−2^⌊log₂n⌋)（n 为 2 的幂时得 0）——正确形式是 2^⌊log₂n⌋，本轮已据此修正原解答。写完务必用小规模暴力模拟对拍验证。

## 模型相关手撕

- **手撕：MHA（Multi-Head Attention）** —— PyTorch 默写：QKV 投影、reshape 成多头、scaled dot-product、输出投影。与 [[20-Areas/实习与求职/面试题与经验/题库/模型基础与训练]] 互链。出处：[[20-Areas/实习与求职/面试题与经验/AI-Agent与大模型岗位面经汇总-01至05-07-08|汇总A·面经07]]
  > [!success]- ✅ AI 解答 · Q149 · 2026-09-29
  > **🎯 标准答案（面试版）**MHA 的 PyTorch 实现五步：①线性投影：x 分别过 W_q/W_k/W_v（d_model→d_model）；②多头拆分：reshape 成 (B, num_heads, seq_len, d_head)，d_head=d_model//h；③缩放点积注意力：scores=Q@K^T/√d_head，因果掩码把未来位置置 −inf，softmax 后 @V；④拼接：transpose+reshape 回 (B, seq_len, d_model)；⑤输出投影 W_o。十行内默写无误并说清每一步 shape 是基本功。
  > **📌 要点**
  > - 缩放因子是 √d_head（不是 √d_model）
  > - 掩码时机：softmax 之前 masked_fill(-inf)；注意 bool mask 语义（True=保留）
  > - shape 坑：用 transpose(1,2) 而不是直接 reshape 拆头（reshape 会把 token 维度切错）
  > - dropout 加在注意力权重上；输出前可再 dropout
  > - 复杂度：O(n²·d) 时间，注意力矩阵 O(n²) 空间
  > **🔬 原理深入**
  > 为什么除以 √d_head？q·k 点积的方差随维度线性增长，不缩放会让 softmax 进入饱和区、梯度趋零；除以 √d_head 把方差归一到 1 量级保证数值稳定。多头的意义：每个头在独立的低维子空间学习不同对齐模式（句法、共指、位置），拼接后经 W_o 融合，等价于注意力的集成。高频追问：①MQA/GQA 如何省 KV Cache——MQA 全头共享一组 K/V，GQA 分组共享，推理显存大幅下降；②为什么自回归解码可缓存 K/V——历史 token 的 K/V 不随新 token 改变，只需算新 token 的 q 与缓存做点积（详见模型基础与训练的 KV Cache 条目）。
  > **🔗 延伸**
  > 与本库模型基础与训练 Q132（KV Cache）、Q131（QKV）互链；进阶：FlashAttention 的分块 IO 优化思想、batch 场景下的 padding mask 与 causal mask 叠加。
  > [!success]- ✅ AI 解答 · Q149 · 2026-10-16（复习轮）
  > **🎯 标准答案（面试版）**手撕关键五行：①`q,k,v = W_q(x), W_k(x), W_v(x)`；②拆头 `q.view(B, T, h, d).transpose(1,2)`（必须 transpose，不能直接 reshape）；③`scores = q @ k.transpose(-2,-1) / math.sqrt(d_head)`；④mask 在 softmax 之前：`scores.masked_fill(mask, -inf)`；⑤`attn = softmax(scores) @ v` → `transpose(1,2).contiguous().view(B,T,d)` → 输出投影。
  > **📌 要点**
  > - 缩放因子是 √d_head，不是 √d_model
  > - reshape 拆不了头：会切错 token 维度，必须 view+transpose
  > - mask 时机：softmax 前；极性：True 表示需屏蔽（masked_fill）
  > - padding mask 与 causal mask 叠加：两者取「或」（任一需屏蔽即屏蔽）
  > - 数值稳定：fp16 下 softmax 前减 max 防溢出
  > **🔬 原理深入**
  > 面试官通常连追问三层：①为什么 √d_head——点积方差随维度线性增长，不缩放会进 softmax 饱和区导致梯度消失；②MQA/GQA 怎么省显存——多个 query 头共享 K/V 头，KV Cache 降为 1/h~1/g，推理吞吐显著提升；③FlashAttention 优化什么——不改变数学结果，靠分块+重计算把注意力矩阵显存从 O(n²) 降到 O(n)，本质是 IO 优化。答出「IO 而非算力才是瓶颈」就是加分点。
  > **🔗 延伸**
  > 与本库 Q131（QKV）、Q132（KV Cache）互链；进阶：GQA 论文、FlashAttention-2。

## 动态规划与回溯

- **给定整数数组，每个数前加 `+` 或 `-` 使和为 target，求方案数（目标和，LeetCode 494）** —— DFS 回溯 + 0-1 背包计数（子集和 DP，注意负号偏移）两种思路都要会并说明复杂度。出处：[[20-Areas/实习与求职/面试题与经验/飞猪-Agent算法-一面面经-Zechariah|飞猪·Zechariah]]
  > [!success]- ✅ AI 解答 · Q150 · 2026-09-29
  > **🎯 标准答案（面试版）**设正号子集和为 P、负号子集和为 N，则 P+N=sum、P−N=target，两式相加得 P=(sum+target)/2。问题转化为「选子集使和恰好为 P 的方案数」——0-1 背包计数 DP：dp[j] 表示和为 j 的方案数，dp[0]=1，对每个 num 逆序枚举容量 j 执行 dp[j]+=dp[j−num]，答案为 dp[P]。剪枝：sum+target 为奇数或 |target|>sum 时直接返回 0。复杂度 O(n·P) 时间、O(P) 空间；DFS 回溯（指数级，可加记忆化）只适合小数据，面试要能写出背包版并讲清转化。
  > **📌 要点**
  > - 转化是题眼：加减号分配 ⟹ 子集划分，P=(sum+target)/2
  > - 无解剪枝：(sum+target) 为奇数或 |target|>sum
  > - 0-1 背包计数：容量必须逆序枚举，防止同一元素重复选取
  > - dp 语义：恰好装满的方案数，dp[0]=1（空集）
  > - DFS+记忆化（状态 (index, 当前和)）可作对照实现
  > **🔬 原理深入**
  > 为什么必须逆序枚举容量？一维滚动数组压掉了「物品」维度，若正序枚举，dp[j−num] 已是本轮更新过的值，等价于物品可重复选（完全背包）；逆序保证每个数只用一次。为什么会出现「无整数解」？加减号把数组分成两个子集，其和的奇偶性由 sum 决定——sum+target 为奇数时 P 不是整数，自然无方案，这是子集划分视角下自然浮现的约束。变体追问：输出具体方案（记录每个数选没选）、只问可行性（bitset 位运算优化 O(n·sum/64)）、数组含 0（0 加正负号和不变，方案数乘 2，注意 DP 中 0 会自我转移需跳过或特殊处理）。
  > **🔗 延伸**
  > 与分割等和子集（LeetCode 416）、子集和问题同族；「计数类背包」范式：选与不选的方案数相加；DFS 版是回溯模板练习，两种写法都要能口头给出复杂度对比（指数 vs 伪多项式）。
  > [!success]- ✅ AI 解答 · Q150 · 2026-10-16（复习轮）
  > **🎯 标准答案（面试版）**转化是题眼：设正号子集和 P、负号 N，则 P+N=sum、P−N=target ⟹ P=(sum+target)/2，问题变成「子集和恰好为 P 的方案数」。先判无解：sum+target 为奇数、|target|>sum、或 P<0 → 返回 0。DP 一维滚动：`dp[0]=1`，对每个 num 逆序 `for j in range(P, num-1, -1): dp[j]+=dp[j-num]`，答案为 `dp[P]`，时间 O(n·P)、空间 O(P)。
  > **📌 要点**
  > - 无解三判据：奇偶性、|target|>sum、P 为负
  > - 逆序遍历的原因：0-1 背包防同一元素被复用（正序即完全背包）
  > - 暴力对照：n≤20 时 DFS 2^n 也可行，面试先说转化再说优化
  > - 变体：求具体方案（DP 记前驱回溯）、最少符号数（换 BFS/最短路思路）
  > **🔬 原理深入**
  > 为什么「转化」比直接 DP 更高分？直接对「加减号」建状态是二维的（当前和 + 已选下标），维度高且语义混乱；转化为子集划分后状态塌缩成一维容量，本质是识别出与「子集和」同构。追问「DP 初始化边界」：`dp[0]=1` 表示空集和为 0 有一种方案，这是所有计数型背包的通式，漏掉会导致结果全 0。
  > **🔗 延伸**
  > LeetCode 494 原题；同族练习：416 分割等和子集（判定型）、518 零钱兑换 II（完全背包对比）、322 零钱兑换（最值型）。
