# AI Agent 与大模型岗位面经汇总（01–05、07、08）

## 汇总信息

- 共 7 组面经，编号为 01、02、03、04、05、07、08；截图中未提供面经 06。
- 岗位类型：AI Agent 开发工程师、AI 应用开发工程师、Agent 算法工程师。
- 时间范围：2025-12-22 至 2026-04-18。
- 公司、面试结果、面试轮次和面试官信息：截图未提供。
- 以下题目按截图原意整理；“拷打实习 / 拷打项目”等口语化表述保留为“实习经历追问 / 项目经历追问”。

## 面经 01

- 面试岗位：AI Agent 开发工程师。
- 面试时间：2026-04-18。

### 题目

1. 先做一个 AI Coding。
2. 介绍 LLM 后训练经历。
3. 如何评价 AI Coding 的效果好坏？
4. 如果以后主要由 AI 写代码，算法工程师会承担什么角色？
5. Agent 在一个细分场景中如何进行微调？
6. 未来 Agent 的发展趋势是什么？
7. 物流场景中存在多条路径，如何设计算法选择 48 小时内到达目的地的路径？

### 主题

- AI Coding 评估与工程师角色。
- Agent 场景适配、微调和发展趋势。
- 约束条件下的路径规划与优化。

## 面经 02

- 面试岗位：AI Agent 开发工程师。
- 面试时间：2026-04-17。

### 实习与项目

1. 介绍实习经历。
2. 项目一：Transformer 细节、Q / K / V、KV Cache，以及 Transformer 为什么适用于多模态。
3. 项目二：知识蒸馏。

### 大模型与 Agent

4. 手撕 Java：内存泄漏问题。
5. 如何解决上下文过长导致的遗忘问题？除了 Prompt，还可以如何解决 AI Coding 代码冗长、复杂的问题？
6. Agent 的运行流程是什么？如何理解 RAG 库和 Agent Skill？
7. 手撕：二叉树遍历。

### 主题

- Transformer、注意力输入和 KV Cache。
- 知识蒸馏、上下文限制与代码生成质量。
- RAG、Agent Skill、Java 内存问题和树遍历。

## 面经 03

- 面试岗位：AI 应用开发工程师。
- 面试时间：2026-04-17。

### 项目与 Agent 架构

1. 介绍 AI 项目经历、业务背景和要解决的问题。
2. Multi-Agent 的设计逻辑。
3. 每个 Agent 是否都有大模型调用？
4. 多 Agent 如何进行区分？Trade-off 是什么？
5. 项目衡量指标是什么？如何跟踪？百分比和统计口径是什么？
6. 半自动化评估流程如何实现？
7. 项目中定义不准确的原因有哪些？
8. 为什么选择 7B 而不是 32B？选择逻辑是什么？

### 微调与 AI Coding

9. 详细介绍微调逻辑、实施方式和本地部署。
10. 微调的关键步骤和常见问题。
11. 举一个使用 AI 编程的例子。
12. 对 AI 的看法。
13. AI 出现之后，自己的工作方式有哪些改变？

### 主题

- Multi-Agent 拆分、模型调用边界和架构取舍。
- 指标定义、评估流程、数据口径与误差来源。
- 7B / 32B 选型、微调、本地部署和 AI Coding。

## 面经 04

- 面试岗位：AI Agent 开发工程师。
- 面试时间：2026-04-16。

### 项目与 Agent 工程

1. 介绍实习经历。
2. 什么是对抗式状态机？
3. 状态机和流式处理有什么区别，分别在什么时候使用？
4. 工作流解决什么问题，用户是谁？
5. 工作流延迟是否较高，如何解决？
6. 减少 Token 消耗体现在哪里？
7. 在华为还做了什么？MCP 和 Skill 主要如何使用？
8. 组件可插拔是什么意思？
9. 多个 Agent 如何处理输入？动态上下文使用什么数据结构？
10. MCP 和 Skill 的区别是什么？
11. 工程中如何处理上下文？
12. RAG 工程中如何处理分块？
13. ReAct 范式如何实现？ReAct 和 CoT 的区别是什么，分别适用于什么场景？
14. Multi-Agent 和 Single-Agent 各自适合什么场景？
15. 是否使用过 LangChain？它的优点是什么？
16. Prompt 工程、Context 工程和 Harness 工程的区别是什么？

### AI Coding 题

17. 编写一个高并发优惠券分发系统：同一用户、同一优惠券有不同分发方案；模块采用继承架构，考虑边界条件；提供完整系统、`main` 函数 Demo、边界约束测试和 README 使用说明。

### 主题

- 状态机、流式处理、工作流编排与延迟优化。
- MCP、Skill、RAG、上下文和可插拔组件。
- ReAct / CoT、Single-Agent / Multi-Agent、Prompt / Context / Harness 工程。
- 面向完整交付的高并发系统设计与 AI Coding。

## 面经 08

- 面试岗位：Agent 算法工程师。
- 面试时间：2025-12-22。

### RAG 与编码模型

1. 介绍 RAG 流程；介绍对编码模型的了解、原理、优缺点，以及如何评估编码模型能力。
2. RAG 有哪些分类？多模态 RAG 有哪些实现框架？伪多模态 RAG 和多模态 RAG 如何实现、有什么区别？CLIP 可以用于哪一类多模态 RAG，为什么？
3. RAG 如何评估？RAG 评估体系中最重要的是什么？
4. 传统 RAG 有什么痛点？介绍 GraphRAG、GraphRAG 的难点，以及 GraphRAG 如何应对增量场景。
5. 介绍负责过的微调工作；大模型微调最重要的是什么？

### 主题

- RAG 流程、分类、评估和增量更新。
- 多模态 RAG、伪多模态 RAG、CLIP 与 GraphRAG。
- 编码模型原理、能力评估和大模型微调。
