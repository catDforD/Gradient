## 岗位职责

- 熟悉 tokenizer、模型消息格式、大模型训练、强化学习或评测链路。

## 方向理解

以下为基于 JD 的分析，而非招聘方补充要求。

这个方向的核心是让不同 Agent 能可靠地接入模型、工具、沙箱和训练评测平台，并提供可长期维护的运行框架与 SDK。工作重点包括接口设计、协议适配、运行状态、轨迹回传、兼容性和故障处理。

可以从三类工程成果理解它：

| 工程成果 | JD 对应内容 | 可展示的证据建议 |
|---|---|---|
| 可复用的 SDK / 组件 | 公共接口、数据建模、扩展与版本演进 | 接口文档、示例、测试、版本变更与迁移记录 |
| 可靠的 Agent 运行能力 | 生命周期、单 / 多 Agent、预算、轨迹 | 运行记录、失败处理、状态与资源控制测试 |
| 跨系统适配能力 | 模型、工具、沙箱、训练评测平台 | 适配器实现、协议转换测试、兼容性说明 |

与已收集岗位相比：

- 网易雷火 LLM Agent 算法岗关注规划、推理、评测及记忆的研究产出；本方向更关注承载 Agent 的框架和基础组件工程。
- 网易雷火 Python 平台岗关注业务后端，并要求使用 Coding Agent 开发；本方向更强调可复用组件与跨系统接口的长期维护。
- 安克 agent 开发岗的 JD 方向尚有待核实，本次不据此推定两者工作相同。
