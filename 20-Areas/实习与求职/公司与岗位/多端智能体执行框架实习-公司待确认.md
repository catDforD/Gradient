## 岗位职责

- 参与多端智能体执行框架的设计与开发，覆盖手机端、桌面端等形态，实现完整执行链路：任务编排 → 工具 / 能力调度 → 动作下发 → 状态回传 → 异常恢复。
- 工具与执行通道调度：设计多类工具 / 能力的调用策略与优先级，保证执行链路稳定、可预期。
- 异步编排与状态管理：事件驱动体系、子任务拆分与合并、并发控制、执行状态机。
- 可观测性建设：trace、日志、埋点和链路追踪，支持线上问题定位与效果分析。
- 评测体系：建设自动化评测集与指标体系，量化任务完整度、稳定性和耗时，并对输出失败归因。
- 安全与权限管控：敏感操作确认、权限窗口、安全兜底等执行侧控制逻辑。

- 计算机相关专业，本科 / 硕士 / 博士在读。
- 满足上述实习时间要求。
- 熟悉 Python 或 JS / TS 至少一门，有 Linux 基础。

Agent 基础知识与端侧经验在原文中列为加分项，未要求同时掌握所有语言或移动平台。
