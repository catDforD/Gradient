## 岗位职责

- 组织一组 AI 像研发团队一样分工：需求与设计、代码实现、找 bug 与测试、迭代直到代码可以运行。
- 使用 Agent Teams 规划任务分配与协作，将需求从立项推进到交付。
- 让 Agent 复用仓库已有接口、遵循团队规范，并在长对话中保留必要上下文。
- 给 Agent 整理团队规范与业务知识，检查执行结果、定位偏差并纠正方向。
- 探索多 Agent 协作交付的具体流程；截图明确表示方向仍在探索，可有人带教。

- 在校研究生或优秀本科生，对 AI 有热情。

- 有一定编程基础，Python / Go / Java 中至少一门，掌握基本 Git。
- 主动、愿意尝试，能阅读英文文档，遇到问题愿意追查原因。
