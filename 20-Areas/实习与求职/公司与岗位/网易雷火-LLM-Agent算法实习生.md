## 岗位职责

- 研究支撑游戏场景 NPC 动态策略调整、多工具协作和长链路任务的 Agent 技术。
- 规划与推理：复杂任务拆解、多步推理、动态规划、反思优化。
- 评估与数据：多步 Agent 轨迹评估、端到端评测、高质量轨迹及偏好反馈数据构建。
- 记忆机制：Agentic Memory 的构建和应用。

## 岗位要求

### 必需条件

- 对深度学习、LLM 有深入理解和实践经历。
- 有 Agent 构建、工具设计、任务规划与推理等研究或实践经验。
- 关注 Agent 前沿研究，熟悉 Post-training、Harness、Agentic Memory、Agentic Search 等技术。
- 自驱、善于思考，能针对给定课题深入研究并开展顶会论文发表工作。

### 加分项

- 以第一作者在 ICLR、NeurIPS、ICML、ACL 等 AI 顶会发表过论文。
- 有 LLM Pre-training、Post-training 或 Agent 框架研究 / 实践经验。
- 参与过开源 Agent 项目，或有复杂业务场景的 Agent 落地经验。

已有一作顶会论文列在“加分项”，不应改写成必须已有论文；不过正文对研究与论文产出能力有明确期待。
