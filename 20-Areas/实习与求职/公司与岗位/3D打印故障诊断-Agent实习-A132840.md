## 岗位职责

- 参与 Agent 系统模块开发与调试，协助开发 Multi-Agent 工作流，参与“感知—诊断—决策—执行”闭环的功能迭代，负责模块单元测试和线上问题排查。
- 将 3D 打印领域的喷嘴堵塞检测、翘曲原因推理、参数补偿逻辑等知识封装为标准化、可复用的 Agent Skills 组件，参与 Skills 注册机制的工程化建设。
- 参与核心 Agent 的提示词设计与迭代优化，协助建立提示词版本管理和自动评估流程，探索 TDAD 等提示词自优化方法在 3D 打印故障场景中的落地。
- 整理 3D 打印故障案例、传感器数据和工艺知识，参与 RAG 知识库的构建、清洗与评估，支持 Agent 故障诊断能力持续增强。
- 跟踪 Agent 工程化、LLM 应用等方向的论文与开源项目，输出技术调研报告，为团队技术选型提供参考。

## 岗位要求

### 基础技术能力

- 熟悉 Python 编程，代码规范、逻辑清晰，能够独立完成有一定复杂度的功能模块。
- 了解大语言模型基本原理，有 Prompt Engineering 实践经验。
- 至少了解一种 AI Agent 开发框架，有跑通 Demo 或课程项目经验者优先。
- 了解向量数据库基本概念，如 FAISS、ChromaDB、Milvus 等；有 RAG 实践经验者优先。

### 学习与工程素养

- 具备良好的自驱力和文档习惯，能够独立拆解任务并按时交付。
- 能够满足每周至少 3 天、连续 3 个月以上的实习要求。

### 加分项

- 有 Claude Code、Codex 等 AI Coding 工具的实际使用经验。
- 对 3D 打印、机器人、工业制造等硬件领域有兴趣或背景知识。
- 有开源项目贡献、技术博客或 GitHub 活跃记录。
- 参与过 Agent / LLM 相关课程项目、比赛或科研课题。
