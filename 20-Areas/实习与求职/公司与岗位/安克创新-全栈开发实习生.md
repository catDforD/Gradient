## 岗位职责

- 参与 IoT 智能硬件 APP 及云端服务的全栈开发，覆盖移动端 Android / iOS、Web 前端、后端服务中的一个或多个方向。
- 使用 Claude Code、Cursor 等 AI 辅助工具提升开发效率。
- 参与需求分析、技术方案设计、编码实现、测试部署全流程。
- 编写单元测试和自动化测试用例，保障代码质量。

## 岗位要求

### 必需条件

- 本科及以上在读，计算机 / 软件工程 / 电子信息等相关专业；满足上述实习时间要求。
- 熟悉至少一门后端语言：Go / Java / Python。
- 熟悉至少一种前端或客户端技术：React / Vue / Java / Kotlin / Swift / Flutter。
- 了解 MySQL / PostgreSQL / Redis 等常用数据库，以及 Kafka / RabbitMQ 等消息队列。页面未明确要求掌握全部列举技术。
- 有良好的学习能力和自驱力，对新技术有好奇心。

### 加分项与偏好

- 有全栈项目经验。
- 有 AI 辅助编程实践，例如使用 Claude Code / Cursor 完成过完整项目；对 Agentic Coding 有兴趣者优先。
