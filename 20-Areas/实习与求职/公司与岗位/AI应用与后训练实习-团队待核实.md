## 岗位目标与职责

目标是将大模型能力转化为可上线、可迭代、成本可控的产品能力，通过数据、模型适配与后训练、评测和实验实现端到端交付，持续提升效果与稳定性。

原文明确“具体职责包括以下相关方向的一项或多项”，实际分工待确认。

### 需求与问题定义

- 深入业务与产品需求，将诉求转换为可执行的 AI 任务。
- 明确目标、边界、优先级和验收口径。

### 方案与应用架构

- 在 Prompt、RAG、微调、Agent 等路线间选型和权衡。
- 设计包含上下文、工具调用、记忆、权限及安全的端到端架构。
- 完成 RAG、Memory、Tool Use、多 Agent 等能力的工程化与生产集成。

### 数据建设与治理

- 搭建数据采集、清洗与标注流水线。
- 探索合成数据、模型自标注等策略。
- 建立版本追踪和质量评估，连接模型训练、业务应用、用户反馈与数据迭代。

### 模型适配与后训练

- 推进基座模型面向垂直行业任务的后训练，包括高质量 SFT、PPO、GRPO 等强化学习与偏好优化方法。
- 改善复杂业务场景的指令遵循、可控性及长链路逻辑推理能力。

### 评测体系与实验

- 面向业务目标设计评测指标与 Rubric，搭建包含人工评审的自动化评测框架。
- 建立离线基准与线上实验体系，包括 A/B、Bandit。
- 监控指标漂移与策略投机，防止效果退化。

### 生产交付与运营

- 负责系统集成、上线发布、线上质量、稳定性及成本。
- 建立监控、告警、兜底与人工接管机制，支持持续迭代。

## 岗位要求

### 基础条件

- 相关专业硕士 / 博士优先，优秀本科生也可考虑。
- 顶会论文、高影响项目和开源贡献属于加分项。

### 专业能力

- 模型与后训练：理解 Transformer / LLM 架构、演进原理与局限；具备 SFT / DPO / RL 的后训练、迭代、数据与评估优化能力，有实际后训练经验。
- Agent 与系统编排：能做任务拆解、多 Agent 协作；熟悉 RAG、Memory、Tool Use（含 MCP / 类协议 / Skills 等）并能工程化落地。
- 数据构建：具备 Data-centric AI 意识，能挖掘和构造后训练所需高质量数据。
- 评测与交付：能搭建 autorater / LLM-as-judge、离线评测、A/B 等评估流程；具备测试、调试、代码评审、安全 / 隐私与质量检查能力，并根据评测结果定位问题。
- 工程与系统：能通过 Vibe Coding 快速构建原型；理解分布式系统、数据库和计算机系统基础；精通至少一门语言，熟练掌握 Python、PyTorch，熟悉 Git 和命令行。
- 框架认知：了解大模型训练与推理框架，如 Megatron-LM、vLLM、DeepSpeed / FSDP。

### 加分与优先项

- ACL、EMNLP、ICLR、NeurIPS、ICML 等顶会论文、高影响项目或开源贡献。
- Agentic RL 训练经验。
- 独立开发过有一定影响力的 AI 应用。
- 合成数据、动作轨迹（Trajectory）构建经验。
- 复杂多步任务的量化评估能力。
- 分布式训练或大规模数据处理经验，如 Hadoop、MaxCompute。
- 对主流 AI 开源项目有贡献。

### 能力特质

- 对 AI、前沿技术和产品有兴趣，保持开放和学习能力。
- 主动体验模型与产品，阅读论文 / 技术报告，快速复现和尝试开源项目。
- 重视方案的简洁、可维护、可扩展，能判断技术适用范围并做选型决策。
