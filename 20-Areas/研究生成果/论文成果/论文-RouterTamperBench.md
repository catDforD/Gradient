## 研究内容

- 研究问题：当 LLM API 路由器能够修改经过它的消息时，哪些修改会传播到 Agent 的实际行动，并产生可验证的安全影响？
- 核心方法：构建端到端基准，将路由器修改映射到不同 API 格式，并以可信的 Agent、工具和环境记录区分投递、下游处理、恢复与实际影响。
- 评估范围：5 个 Agent、6 个模型形成的 30 种配置，以及 3 类 API 格式。
- 主要结论：结构合法的消息仍可能携带有害修改；路由器之外的可信检查与端到端消息认证对限制影响有显著作用。

## 结果与证据

以下为上传稿件第 1—2 页报告的论文整体结果，尚未映射到个人贡献，也未在本次整理中复现实验。

- 基准包含 143 个基础任务、43 种变体、939 个案例；其中 914 个为主动案例，25 个用于测量被动可见性。
- 在 30 种 Agent—模型配置中，每种配置都出现至少一种成功攻击，平均攻击成功率为 31.9%。
- 789 个可比较传播案例中，无路由器外可信检查的一组汇总成功率为 84.1%，有此类检查的一组为 6.0%；这是分组统计，不是个人带来的性能提升。
- 防御覆盖分析推算端到端消息认证下的成功率为 6.5%；属于稿件中的覆盖分析结果。
