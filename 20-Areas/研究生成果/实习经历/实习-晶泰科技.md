## 代表性工作

- 详细项目档案：[[20-Areas/研究生成果/项目经历/项目-ChemSec-Eval|ChemSec-Eval]]。

### 安全评测与数据构建

- 搭建基于 Inspect AI 的评测框架，组织样本、任务入口、模型调用和评分器；以 LLM-as-a-judge 判断输出是否满足风险请求，并保留规则回退与异常分类。
- 开发单任务与批量数据生成工具，结合风险规格和知识种子生成评测数据，改进 Agent 安全样本生成与拒答评分逻辑。
- 项目最终展示数据规模为 **10 万+**；当前仓库分类文档列出 114,035 条静态记录，包含扩展与增强版本，不等同于去重样本量或实际完成的全部评测量。

### 业务 Agent 接入与护栏加固

- 开发 XCurve 的 OpenAI-compatible 适配服务和接口测试，使业务 Agent 能接入统一评测流程；仓库整体同时支持 AiFChem 接入。
- 集成化学风险知识检索、多轮隐私规则与会话状态，结合输入侧风险建议、隐私阈值控制和输出侧泄露扫描形成组合护栏。
- 将组合护栏整理为可独立集成的交付包，提供运行配置、使用说明和结果记录。

### 评测结果与交付

本人于 **2026-09-09 确认成果展示页采用最终评测结果**，按此口径记录：

| 安全方向 | 基线攻击成功率 | 加固后攻击成功率 | 下降幅度 |
| --- | ---: | ---: | ---: |
| 内容安全 | 34.8% | 4.4% | 30.4 个百分点 |
| Agent 安全 | 58.7% | 6.1% | 52.6 个百分点 |
| 隐私安全 | 68.9% | 4.7% | 64.2 个百分点 |

- 最终展示页报告护栏覆盖率 **94.3%**；多轮隐私设计包括 16 个主题、152 个场景和 7 种输出格式。
- 实习期可追溯交付：2026-06-05 提交内容安全、Agent 安全、多轮隐私与 KG 专项共 **33,413 条阶段评测记录**的摘要，保留配置和分片汇总依据。该数量不作为最终展示指标的分母。
- 交付材料：评测代码、生成工具与数据、业务接口适配、组合护栏包、结果摘要和成果展示页。
